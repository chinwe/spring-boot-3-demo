🏷️ 二、注解迁移（@MockBean → @MockitoBean）

Spring Boot 4.0 移除了 @MockBean 和 @SpyBean，替换为 Spring Framework 7 原生的 @MockitoBean 和 @MockitoSpyBean。

📝 注解替换规则
// 注解替换
- @MockBean          →  + @MockitoBean
- @SpyBean           →  + @MockitoSpyBean

// 导入包替换
- import org.springframework.boot.test.mock.mockito.MockBean;
+ import org.springframework.test.context.bean.override.mockito.MockitoBean;

🔧 四、API 行为变更
  • ObjectMapper 不再自动注入 Jackson 2 实例
    Spring Boot 4.0 默认使用 Jackson 3（包名 tools.jackson），不再自动配置 Jackson 2 的 com.fasterxml.jackson.databind.ObjectMapper。 
    - @Autowired
- private ObjectMapper objectMapper;
+ private final ObjectMapper objectMapper = new ObjectMapper();  // 手动创建 Jackson 2 实例
// 或
+ private final ObjectMapper objectMapper = new ObjectMapper().findAndRegisterModules();  // 含 LocalDateTime 支持
    受影响文件：AsyncIntegrationTest、TestControllerMockitoTest、JooqControllerTest、OrikaControllerTest、LoggingTestControllerTest、SentinelIntegrationTest、CircuitBreakerControllerTest（共 7 个）
  • ResponseEntity.getStatusCodeValue() 已移除
    Spring Framework 7 移除了 getStatusCodeValue()，需改用 getStatusCode().value()
    - assertEquals(200, response.getStatusCodeValue());
+ assertEquals(200, response.getStatusCode().value());
    受影响文件：VirtualThreadIntegrationTest.java（3 处）
  • TestRestTemplate 需显式启用自动配置
    Boot 4 中 @SpringBootTest 不再自动提供 TestRestTemplate，需添加 @AutoConfigureTestRestTemplate
    @SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
+ @AutoConfigureTestRestTemplate
public class TestControllerTest { ... }
    受影响文件：TestControllerTest.java
📝 五、主代码（src/main）变更

主代码仅 1 个文件 需要修改，变更量极小：

📄 DesensitizeTestRequest.java
// Jackson 3.x 要求反序列化时有无参构造器，@Builder 会抑制默认构造器
@Data
@Builder
+ @NoArgsConstructor
+ @AllArgsConstructor
public class DesensitizeTestRequest {
    private String email;
    private String phone;
}
💡 说明 Spring Boot 4.0 默认使用 Jackson 3，Jackson 3 要求 POJO 有无参构造器才能反序列化。 由于 @Builder 会生成全参构造器并抑制默认构造器，因此需要补上 @NoArgsConstructor。
